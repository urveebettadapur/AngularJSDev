# AngularJSDev

A collection of practical AngularJS assignments focused on developing core frontend development skills through hands-on implementation.

## Overview

This repository contains three technical assignments designed to strengthen my understanding of AngularJS, form handling, data validation and REST API integration.

Each assignment is implemented independently, with a focus on clean code, practical application and understanding the underlying concepts.

## Assignments

### Assignment 1 – AngularJS Fundamentals
**Status:** Completed

Demonstrates the fundamental concepts of AngularJS through a Farmer Management Dashboard.

**Concepts covered:**
- AngularJS Modules and Controllers
- `$scope` and Two-Way Data Binding
- `ng-model`
- `ng-repeat`
- `ng-if`
- `ng-show`

### Assignment 2 – Farmer Registration Form
**Status:** Completed

Implementation of a Farmer Registration Form with input handling, validation and registration confirmation.

**Concepts covered:**
- AngularJS Forms
- `ng-model`
- Required Field Validation
- Mobile Number Validation using `ng-pattern`
- Validation Error Messages
- Form Submission using `ng-submit`
- Form Validation States
- Conditional Rendering using `ng-if`
- Displaying Registered Farmer Details
- Form Reset using AngularJS Form Methods

### Assignment 3 – REST API Integration
**Status:** Completed

Integration of REST APIs using AngularJS and JSONPlaceholder to retrieve user records and submit new posts.

**Concepts covered:**
- `$http` Service
- GET and POST Requests
- REST API Integration
- JSON Data Handling
- Displaying API Response Data
- Promise Handling using `.then()`, `.catch()` and `.finally()`
- Loading States
- Error Handling
- Form Submission and Validation
- Conditional Rendering using `ng-if`

## Technologies Used

- HTML5

- JavaScript
- AngularJS 1.8.2
- JSONPlaceholder REST API
- Git and GitHub

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/urveebettadapur/AngularJSDev.git
   ```

2. Navigate to the required assignment folder.

3. Open `index.html` in a web browser.

4. Follow the instructions in the respective assignment's README.

**Note:** An internet connection is required to load AngularJS through the CDN and access the JSONPlaceholder API.
